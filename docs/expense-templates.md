# 출장비 정산 엑셀 템플릿 구조 (실측본)

> **무엇**: NetEase OA 출장비 정산(`差旅报销` 차뤼바오샤오)에 업로드하는 **엑셀 템플릿 4종의 셀 구조 실측 기록.**
> **작성**: 2026-08-18. 사용자가 사내 시스템에서 직접 받은 원본 4개를 `openpyxl`·원본 XML로 뜯어 확인.
> **성격**: 이 문서는 **변하지 않는 사실(구조)** 만 담는다. 어떻게 채울지·왜 그렇게 채우는지는 → [expense-context.md](./expense-context.md)
> **표기**: [CLAUDE.md 「중국어를 다루는 법」](../CLAUDE.md) 규약에 따라 원문 + 한국어 + 위치를 항상 병기한다.

---

## 결론 먼저

- 템플릿은 **4개 파일**이고, 각각 **보이는 시트 1개 + 숨김 시트 2개**로 되어 있다.
- **헤더가 전부 `*`로 시작한다 = 모든 항목이 필수.** 한 칸이라도 비면 임포트가 막힐 수 있다.
- **데이터는 2행부터** 넣는다. 1행은 헤더.
- **엑셀을 새로 만들면 안 된다.** 숨김 시트에 시스템 식별 토큰이 들어 있어, 다운로드받은 파일을 열어 **행만 추가**해야 한다.
- **데이터 열이 전부 「텍스트」 서식으로 지정돼 있다** (`numFmtId=49` = 엑셀 내장 `@`). 4개 파일·모든 열 예외 없음. → §2-1

## 1. 파일 4종 — 무엇을 어디에 넣나

| # | 원본 파일명 | 시트명(=탭명) | 한국어 | 열 수 |
|---|---|---|---|---|
| 1 | `差旅报销_机票、火车票_*.xlsx` | `机票_火车票` | **항공권·기차표** | 8 |

## 2. 공통 구조 — 파일 4개 모두 동일

### 시트 3개
| 시트 | 상태 | 역할 |
|---|---|---|
| 항목명 시트 (`个人餐费` 등) | 보임 | **여기 2행부터 데이터를 넣는다** |
| `..._dict` (예: `个人餐费_dict`) | **숨김** | 드롭다운 선택지 원본. 이름 정의(defined name)로 참조됨 |
| `_easeflow_import_info_` | **숨김** | A1에 **파일마다 다른 16바이트 토큰**. 시스템이 "이게 어느 양식인지" 식별하는 값으로 추정 |

> 시트명 `_easeflow_import_info_`에서 이 업로드 파이프라인이 사내 워크플로 엔진 **easeflow(易流)** 임을 알 수 있다.
> 토큰 실제 값은 **의도적으로 이 문서에 적지 않는다** (레포가 PUBLIC이므로). 필요하면 원본 파일에서 직접 읽는다.

### 2-1. 셀 서식 — 데이터 열은 전부 「텍스트」다 *(2026-08-18 실측)*

`xl/styles.xml`을 열어보면 커스텀 서식(`<numFmts>`)은 **없다.** 대신 **내장 서식 `numFmtId=49`(= `@`, 텍스트)** 가 `applyNumberFormat="true"` 와 함께 데이터 열 전부에 걸려 있다. 열 → 스타일 연결은 시트의 `<cols><col style="N">` 이 담당한다.

| 파일 | 데이터 열 | `cellXfs` 인덱스 | `numFmtId` |
|---|---|---|---|
| `机票、火车票` | A~H (8열) | 1~8 | **49 = 텍스트** |
| `酒店费用` | A~H (8열) | 1~8 | **49 = 텍스트** |
| `个人餐费` | A~I (9열) | 1~9 | **49 = 텍스트** |
| `交通费` | A~F (6열) | 1~6 | **49 = 텍스트** |

헤더 1행만 `numFmtId=0` + 분홍 채움(`fillId=3`)으로 따로 잡혀 있다.

**함의**: 날짜를 엑셀 날짜값(시리얼 넘버)으로 넣으면 텍스트 서식 열이라 `46252` 같은 숫자로 보인다. **양식 제작자가 문자열 입력을 전제했다는 증거**다. 어떤 문자열 포맷으로 쓸지는 → [expense-context.md](./expense-context.md)

재현:
```bash
unzip -p 差旅报销_个人餐费_*.xlsx xl/styles.xml | grep -o '<cellXfs.*</cellXfs>'
unzip -p 差旅报销_个人餐费_*.xlsx xl/worksheets/sheet1.xml | grep -o '<cols>.*</cols>'
```

### 그래서 지켜야 할 것
1. **새 워크북을 만들지 않는다.** 원본을 복사해서 그 복사본에 행을 추가한다.
2. **숨김 시트를 지우거나 건드리지 않는다.** `openpyxl`로 열고 저장할 때 숨김 시트가 보존되는지 확인할 것.
3. **파일명은 바꿔도 된다** — 시스템이 읽는 건 파일 내용이지 파일명이 아니다. 다만 서버가 파일명까지 검사하는지는 **미확인**이므로, 원본 접두어(`差旅报销_机票、火车票_`)는 남기고 뒤만 바꾸는 것을 권장.

### 데이터 유효성 검사(드롭다운) 적용 범위
드롭다운이 걸린 열은 **2행 ~ 65534행**에 적용돼 있다. 목록에 없는 값을 넣으면 엑셀이 `此值与单元格定义格式不一致！`(이 값은 셀에 정의된 형식과 맞지 않습니다) 오류를 낸다.

## 4. `币种`(통화) 값 — 화면 드롭다운 실측

엑셀 템플릿의 B열(`酒店费用`은 C열) `币种`에는 드롭다운이 없어 자유 입력이지만, **화면 폼의 드롭다운 표기는 `코드-중국어명` 형식**이다. 실측한 목록:

| 값 (그대로 입력) | 한국어 |
|---|---|
| `CNY-人民币` | 중국 위안 |
| `HKD-港币` | 홍콩 달러 |
| `USD-美元` | 미국 달러 |
| `EUR-欧元` | 유로 |
| `GBP-英镑` | 영국 파운드 |
| `KRW-韩元` | **한국 원** |
| `JPY-日元` | 일본 엔 |
| `AUD-澳大利亚元` | 호주 달러 |
| `CAD-加拿大元` | 캐나다 달러 |
| `TWD-新台币` | 대만 달러 *(화면에서 잘려 부분 확인)* |

> 목록은 스크롤이 더 남아 있어 **위가 전부는 아니다.** 필요한 통화가 없으면 화면에서 다시 확인할 것.
> **엑셀에 `CNY-人民币` 전체를 넣을지 `CNY`만 넣을지는 미확정** — 첫 업로드로 검증한다.

## 5. 화면 폼 vs 엑셀 템플릿 — 덮는 범위가 다르다

NetEase OA 화면(`报销项目明细` 정산 항목 상세)의 `交通费` 탭 컬럼과 엑셀 템플릿을 대조한 결과:

| 화면 컬럼 | 한국어 | 엑셀에 있나 |
|---|---|---|
| `*发生日期` `*币种` `*本次支付金额(原币)` `*出发地点` `*抵达地点` `*详细说明` | (위 §3-4와 동일) | ✅ 있음 |
| **`*是否国际/港澳台出差`** | 국제/홍마대 출장 여부 | ❌ **없음** (화면에선 필수) |
| `发票` | 인보이스(파피아오) 첨부 | ❌ 화면에서 `+` 버튼으로 업로드 |
| `行程单` | 여정표 첨부 | ❌ 화면 업로드 |
| `费用相关证明` | 비용 관련 증빙 첨부 | ❌ 화면 업로드 |
| `兑付款币种汇率` | 지급 통화 환율 (기본 `1.0000`) | ❌ 시스템 자동 |
| `本次支付金额` | 이번 지급액(위안 환산) | ❌ 시스템 자동 계산 |

**함의 2개**
1. **`交通费`의 국제출장 여부는 엑셀로 못 채운다.** 임포트 후 화면에서 채워야 할 가능성이 크다 → 첫 업로드 때 확인.
2. **영수증 파일 첨부는 엑셀 임포트 범위 밖이다.** 엑셀은 텍스트 값만 채운다.

### 화면 구조 (참고)
- 정산서 제목 형식: `差旅报销-{신청자 영문 이름}-{날짜}` — 시스템이 자동 생성한다 *(실명 예시는 이 레포가 PUBLIC이라 싣지 않는다)*
- `报销项目明细`(정산 항목 상세) 안에 **탭 4개가 공존**: `机票、火车票` / `酒店费用` / `个人餐费` / `交通费` → **정산서 1건에 4개 파일이 모두 들어간다.**
- 탭 옆에 `业务招待费`(업무 접대비) `团建费`(팀빌딩비) 추가 버튼이 따로 있다 → **다른 비용 유형은 별도 템플릿**일 것.
- 엑셀 업로드 진입점 = **`Bulk Import`** 버튼. 옆에 `批量上传发票`(인보이스 일괄 업로드), `Add details`(행 직접 추가).
- `报销汇总`(정산 요약)의 `申请付款总金额`·`本次支付总金额`은 **자동 합계**.

## 6. 재현 방법 — 구조를 다시 확인하고 싶을 때

템플릿을 새로 받았을 때 이 문서와 달라진 게 없는지 확인하는 스크립트:

```python
import glob, openpyxl
for path in sorted(glob.glob('差旅报销_*.xlsx')):
    wb = openpyxl.load_workbook(path)
    print(path, [(ws.title, ws.sheet_state) for ws in wb.worksheets])
    ws = wb.worksheets[0]
    print("  헤더:", [c.value for c in ws[1]])
    for dv in ws.data_validations.dataValidation:
        print("  드롭다운:", dv.sqref, "→", dv.formula1)
    for n in wb.defined_names:                      # 드롭다운 선택지 실제 값
        ref = wb.defined_names[n].value
        print("  ", n, ref)
```

> 파일명을 `inspect.py`로 저장하면 파이썬 표준 모듈 `inspect`와 충돌해 실행이 깨진다. 다른 이름을 쓸 것.
