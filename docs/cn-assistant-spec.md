# 중국어 소통 보조 — 기준 문서

> **무엇**: 중국 회사(NetEase) 신입으로서의 **중국어 소통 병목**을 Claude로 푸는 기준. 출력 포맷·구현 계획·컴플라이언스 라인.
> **작성**: 2026-08-10. 관련: [popo-automation-context.md](./popo-automation-context.md)

---

## 왜 이게 1순위인가

발굴·점수화(artist-pickup)나 딜 제안서(deal-proposal)는 이미 도구가 있다. **지금 실제 병목은 중국어 소통**이다. 본업 도구를 더 만드는 것보다 이걸 먼저 푸는 게 체감 효과가 크다.

**사용자 병목(본인 진술)**
1. 단어가 무슨 의미인지 파악이 어렵다
2. 뜻을 이해해도 **발음·성조**를 몰라 매번 따로 찾아본다 → 시간 소모

→ 이건 *번역* 문제가 아니라 **해독 + 학습** 문제다. 일반 번역기로 안 풀린다.

---

## 핵심 지렛대 — 한국 한자음 매핑

중국어 업무 어휘 대부분이 **한국 한자음과 1:1 대응**한다. 사용자가 이미 아는 단어다.

| 중국어 | 병음 | 한국 한자음 | 뜻 |
|---|---|---|---|
| 报告 | bàogào | 보고(報告) | 보고(서) |
| 确认 | quèrèn | 확인(確認) | 확인 |
| 版权 | bǎnquán | 판권(版權) | 저작권 |
| 归属 | guīshǔ | 귀속(歸屬) | 귀속 |
| 方案 | fāng'àn | 방안(方案) | 안·제안서 |

**모든 출력에 한자음 열을 반드시 넣는다.** 의미 암기 비용이 사실상 0이 되고, 성조만 따로 외우면 된다. 일반 번역기가 절대 안 해주는 것 = 이 도구의 차별점.

**함정도 같이 표시한다** (한자음이 통하지 않는 것):
`爱人`=배우자(애인 아님) · `工作`=일·직장(공작 아님) · `汽车`=자동차 · `走`=가다(달리다 아님)

## 출력 포맷 — 5단 (정본)

중국어 메시지를 입력하면 **항상 이 순서**로 낸다.

### ① 결론 한 줄
무슨 말인지 + **나한테 뭘 원하는지**. 액션과 기한을 앞에.

### ② 문장 분해 (표)
`원문 | 병음(성조 부호) | 한국어`

### ③ 단어장 (표) — 그대로 용어집에 누적
`단어 | 병음 | 한국 한자음 | 뜻` (+ 함정이면 비고)

### ④ 뉘앙스 — 직역하면 놓치는 것
중국 회사 메신저의 완곡어법을 실제 의미로 풀어준다. 자주 나오는 것:

| 표현 | 표면 | 실제 |
|---|---|---|
| 我先看看 | "일단 볼게" | **보류 · 즉답 회피.** 승인 아님 |
| 辛苦了 | "수고했어" | **화제 종료 신호.** 뒤에 오는 게 진짜 용건 |
| 麻烦…一下 | 정중한 부탁 | 사실상 **지시** |
| 方便的话 | "가능하면" | 사실상 **기한 통보** |
| 再看看 / 再说吧 | "더 보자" | 사실상 **보류·거절** |

### ⑤ 답변 초안 — 읽고 말할 수 있게
중국어 + **병음** + 한국어 역번역. 필요 시 톤별(격식/중립/친근). 존칭 `您 nín` 사용 여부 명시.

> **원칙: 초안은 만들어만 준다. 발송은 사람이 손으로.** ([popo-automation-context.md](./popo-automation-context.md) §3-4)

## 워크드 예시 (포맷 검증용)

**입력**
> 这个方案我先看看，辛苦了。另外下周之前麻烦确认一下版权归属的问题，方便的话周三之前给我答复。

**① 결론** — 제안서는 **보류(즉답 회피)**. 실제 액션은 **수요일까지 판권 귀속 확인해서 회신.**

**② 분해**

| 원문 | 병음 | 한국어 |
|---|---|---|
| 这个方案我先看看 | zhège fāng'àn wǒ xiān kànkan | 이 안은 일단 좀 볼게요 |
| 辛苦了 | xīnkǔ le | 수고하셨어요 |
| 另外下周之前麻烦确认一下版权归属的问题 | lìngwài xiàzhōu zhīqián máfan quèrèn yíxià bǎnquán guīshǔ de wèntí | 그리고 다음 주 전까지 판권 귀속 문제 확인 부탁드려요 |
| 方便的话周三之前给我答复 | fāngbiàn dehuà zhōusān zhīqián gěi wǒ dáfù | 가능하면 수요일 전까지 답변 주세요 |

**③ 단어장**

| 단어 | 병음 | 한국 한자음 | 뜻 |
|---|---|---|---|
| 方案 | fāng'àn | 방안 | 안·기획서 |
| 辛苦 | xīnkǔ | 신고(辛苦) | 수고 |
| 麻烦 | máfan | 마번(麻煩) | 번거롭지만~ (정중한 요청) |
| 确认 | quèrèn | 확인 | 확인 |
| 版权 | bǎnquán | 판권 | 저작권 |
| 归属 | guīshǔ | 귀속 | 귀속 |
| 答复 | dáfù | 답복(答復) | 답변·회신 |

**④ 뉘앙스** — `我先看看`=보류 신호(재촉 금지) · `辛苦了`=화제 종료, 뒤가 진짜 용건 · `麻烦…一下`=형태는 부탁, 실질은 지시 · `方便的话`=사실상 수요일 데드라인

**⑤ 답변 초안**
> **好的，我这边先确认版权归属，周三之前给您答复。**
> hǎo de, wǒ zhèbiān xiān quèrèn bǎnquán guīshǔ, zhōusān zhīqián gěi nín dáfù.
> *좋습니다, 제가 먼저 판권 귀속을 확인해서 수요일 전까지 답변드리겠습니다.*
> — `您 nín` = 존칭. 상급자·타 부서에 사용.

## 구현 계획 A / B / C

**환경 전제**: POPO = 회사 지급 PC · Claude Code = 개인 맥 · **회사 PC에 Claude 데스크톱 설치 가능**(확인됨) → 붙여넣기 루프가 **회사 PC 안에서 완결**된다.

| | 산출물 | 위치 | 용도 | 상태 |
|---|---|---|---|---|
| **A** | Claude 데스크톱 **Project 지침**(복붙용 텍스트) | 회사 PC | 실전. 중국어 붙여넣으면 5단 세트 출력 | ✅ **완료** → [cn-assistant-project-instructions.md](./cn-assistant-project-instructions.md) |
| **B** | `popo-cn` 스킬 | 이 레포 / 개인 맥 | 같은 로직 + 용어집 자동 누적·관리 | 미착수 |
| **C** | `data/cn-glossary.md` 용어집 | 이 레포 | 회사 PC에서 나온 단어를 주기적으로 누적 | 미착수 |

**입력 범위 = 중국어 텍스트 붙여넣기만** (2026-08-10 확정, 결정 #013). 스크린샷·파일은 범위 밖.
근거: ① 컴플라이언스 라인이 명확해진다("텍스트만, 민감정보는 빼고") ② 캡쳐엔 무관한 대화·이름·워터마크가 딸려 들어가 사외 반출 범위가 넓어진다 ③ 신입이 사내 화면을 외부 AI에 올리는 습관이 붙는 게 위험하다 ④ 지금 병목(단어·성조)엔 텍스트로 충분하다(YAGNI). 스크린샷은 필요할 때 사용자가 **개별 판단해서** 던진다.

**순서 근거**: A를 먼저 며칠 실사용해서 불편한 지점을 찾은 뒤 B·C를 만든다. 완성도보다 실사용 피드백이 먼저.
**C가 장기 자산**: 부서·직책 명칭, 사내 축약어, 동료 이름 한자↔한글 표기, 반복 업무 표현이 쌓이면 번역기가 못 따라오는 개인 자산이 된다.

## 컴플라이언스 라인 (A 지침 첫 줄에 박을 것)

**사내 메시지를 claude.ai에 붙여넣는 것 = 회사 밖으로 내용을 내보내는 행위다.**

- ✅ 괜찮음: 일정·업무 지시·일반 용어·공개 리포트
- ⚠️ **빼고 붙인다**: 계약 조건 · 미공개 아티스트 정보 · 금액 · 개인정보
- 📋 권장: POPO `IT Helper`에 *"업무용으로 외부 AI 서비스 사용 가능한지"* 확인해두기 (신입일수록 먼저 묻는 게 유리)
