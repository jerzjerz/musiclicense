# MV 기획안(컨셉 덱) 틀 — Achilles 포맷 기준

> 2026-11-17 확정 (결정 #028). 제작사 Achilles가 보낸 JOSHUA 《24hours》 M/V Concept Proposal(38쪽)의 구성을 우리 기본 틀로 삼음.
> 첫 적용: LIGHTS(TOPBARRY × YEJI) — 감독 프리비주얼을 이 틀로 옮긴 덱 15쪽(정본은 레포 밖 `materials/topbarry x yeji - LIGHTS/_source/concept-deck/`).
> 앞으로 MV 컨셉·콘티 정리는 **이 페이지 순서를 그대로** 따름. 빼거나 합치지 않음(없는 항목은 "미정"으로 남김).

## 1. 페이지 순서 (한 컨셉 = 아래 1세트)

| # | 페이지 | 담는 것 | 규칙 |
|---|---|---|---|
| 1 | **COVER** | 아티스트 / 곡명 / "M/V Concept" / 작성 주체·날짜(YYMMDD) | 어두운 풀블리드 이미지 1장 + 중앙 정렬 텍스트만 |
| 2 | **SECTION DIVIDER** | `01 CONCEPT` + 컨셉명(영문 대문자 이탤릭) + 한국어 한 단어 칩 | 컨셉이 여러 개면 컨셉마다 디바이더 반복 (`02`, `03`) |
| 3 | **OVERVIEW** | 컨셉명 · 한 줄 부제 · **4행 시놉시스 박스** · 키워드 3개 | 시놉시스는 4행을 넘기지 않음. 키워드는 영문 1단어 ×3 |
| 4 | **KEYWORD** | 키워드 3개 각각: 대표 이미지 1 + 2~3행 설명 | 키워드 = 이야기의 3단(전·중·후)과 1:1 |
| 5 | **STRUCTURE** | 곡 구조 타임라인(구간·타임코드) + 3단 요약(이미지·제목·3~4행) + 노란 한 줄 결론 | 타임코드 출처(데모 버전)를 각주로 명시 |
| 6~n | **키워드별 상세** | 상단: `컨셉명 + 키워드 칩` / 2행 서술 / **노란 "→" 핵심 한 줄** · 하단: 레퍼런스 보드(큰 1 + 작은 4~6) | 이미지마다 `VIDEO`/`PRE-VIS` 칩 + `→ REF:` 캡션. 키워드당 1~2쪽 |
| n+1 | **DEVICE · TECHNIQUE · EDIT** | 장치·기법·편집 3~4개 타일 | 감독 제안은 `PROPOSAL` 칩으로 구분 |
| n+2 | **SHOT LIST** | 구간 / TC / 내용 / 원문 / 출처 표 | 우리 틀에서 추가한 페이지. 출처 열 = 누구 아이디어인지(●색점) |
| n+3 | **CHECK** | 기존 정본(시놉시스·브리프) 대비 유지 / 차이 / 확인 필요 3열 | 우리 틀에서 추가. 외부 발송본에선 뺄 수 있음 |
| n+4 | **ANIMATIC** | 프리비주얼·레퍼런스 영상 프레임 그리드(12장, 4×3) | 원본 영상 파일명·수신일 각주 |
| 끝 | **E.O.D** | 제작사명 / 아티스트 – 곡명 | |

Achilles 원본엔 컨셉 사이에 **「기존 드라마타이즈 형식의 한계 → NEW APPROACH」** 설득 페이지(로케이션 한계·촬영 시간·익숙한 서사)가 있음. 대안 컨셉을 제안할 때만 넣음.

## 2. 타이포·룩
- 배경 검정(#050505) + 미세한 그레인. 텍스트 흰색. **강조는 노랑(#F4F23A) 한 색만** — 칩(배경 노랑·글자 검정)과 핵심 문장에만.
- 영문 디스플레이: 기하학 산세리프 이탤릭(이 PC: Century Gothic). 한국어: Noto Sans KR. 헤더는 좌 `01 | CONCEPT` · 중앙 이탤릭 자간 넓은 섹션명 · 우 쪽번호.
- 이미지 캡션은 `→ REF:` / `→ 구간명:` 으로 시작. 한국어 뜻 + 원문(작게) 병기 — 감독 자막·영문 지시를 옮길 때 원문을 버리지 않음.
- 한국어 문장은 문서 정리형(~함/~임). 인용 카피만 예외.

## 3. 만드는 법 (이 PC)
- HTML 1장 = 1페이지(`@page 1920px 1080px`) → Edge headless `--print-to-pdf`. 스크립트 예: LIGHTS `_source/concept-deck/build_concept.ps1 -Tag MMDD`.
- 영상에서 프레임이 필요하면 ffmpeg 없이 **Media Foundation SourceReader(C# Add-Type)** 로 1초 간격 추출 → 자막·진행바가 박힌 프레임은 16:9로 안쪽 크롭(예: 1280×720 → (106,48) 1067×600).
- 제작사 PDF는 이미지형이므로 `tools/pdfrender.ps1`로 읽음.
- 레퍼런스 스틸은 외부 저작물이라 **레포에 커밋하지 않음**. 덱 소스·이미지는 전부 레포 밖 `materials/`.
